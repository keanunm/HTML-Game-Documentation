# HTML Game Documentation & Tutorial

An interactive, web-based tutorial that guides you through the basics of building styled and functional websites, moving into game development fundamentals using the HTML5 Canvas.

## 🚀 Features

- **Interactive Lessons**: Learn by doing with embedded code snippets and real-time results.
- **Quizzes**: Test your knowledge of HTML IDs, classes, and elements as you progress.
- **Live Sandbox**: Modify CSS values like border-radius and background color to see instant changes.
- **Game Dev Basics**: 
  - Drawing on Canvas
  - Basic movement with buttons
  - Real-time keyboard input (W, A, S, D)
  - Implementation of a basic `gameLoop`

## 📂 Project Structure

- `index.html`: The main structured content and tutorial text.
- `style.css`: Modern dark-mode styling and code-block highlighting.
- `script.js`: Interactive logic, quiz handling, and the canvas game engine.

## 🛠️ How to Use

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Follow the instructions on the page to learn and interact with the elements!
