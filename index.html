Introduction

This is how to create a base for your website! First, make a index.html and write this basic setup!


<!DOCTYPE html>

<html>
    <head>
        <style>
        
        </style>

        <title>My Website</title>
    </head>
    <body>
        
    </head>
</html>

Now I want to add some text! To add a header, do this:

<h1></h1>

You can also use it as a h2, h3, h4, h5, and h6 and also use p for paragraphs

How to create a button!

The HTML should have a button with the "id" attribute like this:

<button id="button">Press me!</button>

Next you should add a <script> inside the "body" and write this code:


let button = document.getElementById("button"); // This gets the button we created

button.addEventListener("click", dissapear)  /* Makes it so the function is called
Upon clicking the button. */

function dissapear() {
    button.style.opacity = 0; // Poof! Our button vanished from existance!
    setTimeout(function() {
        button.style.opacity = 1; // Back into existance!
    }, 2000); // Wait for 2000 milliseconds then run function "Back into existance!"
}

Now look at our button! I will render it underneath!

Note: You can change the style to anything valid like width or others! Have fun changing it :D

What about style?

Add a <style> in the <head> and here is how to change the style:


.button { /* <- the dot means it is the class="button"
    The style */
}
#button { /* <- the # means it is the id="button"
        The style */
}
h1 { /* <- just h1 so <h1> is the targeted element.
    The style */
}

Now if you paid attention, which one are we using? An ID, a CLASS or an ELEMENT?

This is the style for the button!


#button {
    padding: 5px;
    background-color: gray;
    border-radius: 8px;
}

Now click this button underneath to see the style!

Change the values! These are just the default ones! (You may need to click the button twice again.)

Canvas!

Have you ever wondered how to make an object move in a canvas? Well I will teach you.
So the first step is to write this in our "index.html"

<canvas id="mycanvas" width="100px" height="100px"></canvas>

To use style, add this in your <style>.


canvas {
    border: 1px solid blue;
    border-radius: 10px;
    background-color: white;
}

I am going to add some simple movement buttons underneath. I think you have read how to add a button earlier!

To draw a square you need an event listener and functions linked to the buttons like this: (Note: IDs might not be the same for you.)


// Canvas buttons
let right = document.getElementById("right");
let left = document.getElementById("left");
let mycanvas = document.getElementById("mycanvas");
let ctx = mycanvas.getContext("2d");
// Value
let bx = 50;
let by = 50;

// EventListeners
right.addEventListener("click", function() {
    bx += 5;
});

left.addEventListener("click", function() {
    bx -= 5;
});

function draw() {
    ctx.clearRect(0, 0, 100, 100);
    ctx.fillStyle = "red";
    ctx.fillRect(bx, by, 10, 10);
    requestAnimationFrame(draw);
}

Now what about Key Presses? That would be AMAZING. To add key presses, create a new canvas! (Play the simulation with W A S D)


Here is how to do it.


// Get our canvas
let canvas = document.getElementById("keyPresses");
let ctx = canvas.getContext("2d");
// Variables
let W = false;
let S = false;
let A = false;
let D = false;

let px = 50;
let py = 50;

// Add event listeners
document.addEventListener("keydown", function(event) {
    if (event.key === "w") {
        W = true;
    }
    if (event.key === "s") {
        S = true;
    }
    if (event.key === "a") {
        A = true; 
    }
    if (event.key === "d") {
        D = true;
    }
});
document.addEventListener("keyup", function(event) {
    if (event.key === "w") {
        W = false;
    }
    if (event.key === "s") {
        S = false;
    }
    if (event.key === "a") {
        A = false; 
    }
    if (event.key === "d") {
        D = false;
    }
});

function gameLoop() {
    if (W) {
        py -= 1;
    }
    if (S) {
        py += 1;
    }
    if (A) {
        px -= 1;
    }
    if (D) {
        px += 1;
    }

    ctx.fillStyle = "red";
    ctx.clearRect(0, 0, 100, 100);
    ctx.fillRect(px, py, 10, 10);

    requestAnimationFrame(gameLoop); 
}

gameLoop();
